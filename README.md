# rexbrahh Homebrew Tap

Homebrew tap for Rex Liu's macOS apps and command-line tools.

## Usage

```sh
brew tap rexbrahh/tap
brew install rexbrahh/tap/phi
brew install --cask cleanroom
brew install --cask icloud-guard
```

## Contents

- `Casks/` contains GUI app casks.
- `Formula/` contains command-line tools, including Phi (Node.js, Git, and GitHub CLI).
